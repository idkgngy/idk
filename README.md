# Neon Strike Arena

A small multiplayer browser FPS for local play with friends.

## Run it

```bash
npm install
npm start
```

Open `http://localhost:8000`, then share the forwarded port with friends. Each browser joins the same free-for-all arena. The server owns player state, shooting, eliminations, scores, and respawns.

Controls: `WASD` move, `Space` jump, mouse look, left click fire, `Esc` release cursor.
